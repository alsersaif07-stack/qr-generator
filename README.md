# 🎨 مولّد QR

تطبيق ويب بسيط وأنيق لتوليد رموز QR من النصوص أو الروابط، مع إمكانية تخصيص الحجم والألوان وتحميل الصورة.

## ✨ المزايا

- 📝 توليد QR من أي نص أو رابط
- 🎨 تخصيص لون الرمز ولون الخلفية
- 📏 التحكم في حجم الصورة (100 - 1000 بكسل)
- ⬇️ تحميل الصورة بصيغة PNG
- 📋 نسخ الصورة إلى الحافظة مباشرة
- 📱 تصميم متجاوب يعمل على الجوال والكمبيوتر
- 🌐 يعمل بدون إنترنت (المكتبة محلية)

## 🛠️ التقنيات المستخدمة

- HTML5 — هيكل الصفحة
- CSS3 — التصميم والتنسيق
- JavaScript — منطق التطبيق
- qrcodejs — مكتبة توليد QR

## 🚀 طريقة التشغيل

### الطريقة الأولى: مباشرة
1. حمّل المشروع
2. افتح index.html في المتصفح

### الطريقة الثانية: Live Server
1. افتح المشروع في VS Code
2. اضغط Ctrl + Shift + P
3. اكتب: Live Server: Open with Live Server
